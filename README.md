# Cancer Classification Dashboard

Dashboard interakti untuk melakukan klasifikasi kanker berdasarkan data dan karakteristik yang dimasukkan oleh pengguna. Aplikasi ini dirancang untuk menampilkan hasil prediksi model klasifikasi serta membantu pengguna memahami hasil klasifikasi melalui antarmuka yang sederhana dan interaktif.

## Tujuan

Dashboard ini dikembangkan untuk:
1. Mempermudah pengguna dalam melakukan klasifikasi kanker melalui antarmuka berbasis web.
2. Menampilkan hasil prediksi berdasarkan input yang diberikan pengguna.
3. Menyajikan informasi hasil klasifikasi secara interaktif dan mudah dipahami.

## Fitur

- **Input Data:** Pengguna memasukkan karakteristik atau fitur yang dibutuhkan oleh model.
- **Cancer Classification:** Melakukan prediksi kelas kanker menggunakan model machine learning, yaitu Support Vector Machine (SVM).
- **Prediction Result:** Menampilkan hasil klasifikasi berdasarkan data yang dimasukkan.
- **Interactive Dashboard:** Menyediakan antarmuka interaktif yang dapat digunakan secara langsung melalui browser.

## Teknologi yang Digunakan

- Streamlit
